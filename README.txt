HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code, or double-click index.html to preview in a browser.
3. Keep all files in the same folder so styles, scripts, images and the CV load correctly.

HOW TO UPDATE PROJECTS
Edit projects.js. Keep status values as completed, in-progress or planned. Only add public screenshots, demo links and repository links that are safe to share.

PUBLISHING
The site is a static HTML/CSS/JavaScript website and can be published with GitHub Pages. Upload the contents of this folder (not the ZIP itself) to the root of a public repository, then select Settings > Pages > Deploy from a branch > main > /(root). GitHub Pages may take several minutes to publish.
